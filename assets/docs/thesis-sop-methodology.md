# Stage 0-5 论文写作 SOP 方法论

## 概述

用户自创的 Stage 0-5 论文写作 SOP，将论文写作视为软件项目管理，通过六个阶段的系统化流程确保论文质量和可复现性。

## 六阶段流程

### Stage 0: 需求分析 & 数据收集
- 明确论文研究问题和目标
- 收集和整理相关文献
- 确定数据来源和收集方法

### Stage 1: 架构设计与实验规划
- 设计模型架构（如 RoBERTa 双任务 ABSA 四头架构）
- 规划实验方案（消融实验、对比实验等）
- 制定数据标注策略和 pipeline

### Stage 2: 代码实现与训练
- 实现模型代码
- 执行数据标注（2000 条银标 + 300 条金标）
- 训练模型并记录参数

### Stage 3: 质量审计与验证
- 使用"审计提示词"让 VS Code 批量检查论文章节
- 逐字体核对 WPS 排版规范
- 验证实验结果的可复现性（固定随机种子、一致性 hash 校验）

### Stage 4: 文档编写与可视化
- 撰写论文各章节
- 制作图表和可视化
- 确保格式符合学术规范

### Stage 5: 答辩准备 & 复盘
- 准备答辩材料
- 模拟答辩问答
- 复盘整个项目，总结经验教训

## 核心特点

### 工程化管理
- 将论文视为软件产品来管理
- 每个阶段有明确的输入、输出和验收标准
- 使用版本控制（Git）管理论文迭代

### 质量保障机制
- **审计提示词**: 自动化检查论文质量
- **排版规范**: 逐字体核对 WPS 格式
- **可复现性**: 固定随机种子、一致性 hash 校验

### 工具链支持
| 工具 | 用途 |
|------|------|
| VS Code | 代码编写、审计检查 |
| WPS | 论文排版 |
| Git | 版本控制 |
| Obsidian | 知识库管理 |

## 应用价值

1. **降低焦虑**: 将大任务分解为可管理的小阶段
2. **保证质量**: 每个阶段都有质量检查点
3. **提高效率**: 避免重复工作和返工
4. **增强可复现性**: 系统化的记录和验证
