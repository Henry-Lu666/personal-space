🤖 Agent 执行

底层架构：多级列表与样式绑定

Agent 目标：生成 VBA 宏代码，一键解决最繁琐的「1.1、1.1.1」多级列表与标题 1/2/3 的绑定，并设置基础中英文字体。

Agent 生成指令（复制此代码到 WPS/Word 的 VBA 编辑器运行）：

Sub SetupThesisStyles()
    '绑定多级列表到标题
    With ListGalleries(wdOutlineNumberGallery).ListTemplates(1).ListLevels(1)
        .NumberFormat = "%1."
        .LinkedStyle = "标题 1"
    End With
    With ListGalleries(wdOutlineNumberGallery).ListTemplates(1).ListLevels(2)
        .NumberFormat = "%1.%2."
        .LinkedStyle = "标题 2"
    End With
    With ListGalleries(wdOutlineNumberGallery).ListTemplates(1).ListLevels(3)
        .NumberFormat = "%1.%2.%3."
        .LinkedStyle = "标题 3"
    End With

    '设置中英文字体
    With ActiveDocument.Styles("标题 1").Font
        .NameFarEast = "黑体" '中文
        .NameAscii = "Times New Roman" '英文
        .Size = 16 '三号
    End With
    MsgBox "基础架构搭建完成！"
End Sub

注：由于 VBA 操作 WPS/Word 列表的兼容性，若代码报错，Agent 也可通过生成 XML 模板文件供人类导入。

🤖 Agent 执行

内容填充：纯文本与样式套用

Agent 目标：将大纲和正文写入文档，但绝不带入任何外部格式（防污染），并自动套用对应的标题样式。

Agent 执行逻辑：

  • 使用 API 以 PasteFormat=wdFormatPlainText 写入文本。
  • 遍历段落，识别到章名时，API 赋予 Style="标题 1"。
  • 识别到节名时，赋予 Style="标题 2"，以此类推。

👨‍💻 人工接管

视觉微调：段落细节与孤行控制

机器无法感知「阅读的美感」，以下是需要你手动微操的清单：

微操 1：防止孤行与寡行
右键样式 → 段落 → 换行和分页 → 勾选「孤行控制」。确保段落首行不在页尾，末行不在页首。
微操 2：段前段后间距微调
如果标题正好在页面最上方，段前间距会失效。人工检查并微调标题 1/2 的段前段后距离，让版面透气。
04
👨‍💻 人工接管

复杂元素：表格与图片的锚定

表格和图片是排版崩溃的重灾区，AI 无法判断图表与正文的空间关系，必须人工介入。

微操 1：表格属性设置
选中表格 → 右键表格属性 → 文字环绕选「无」 → 行选项卡取消勾选「允许跨页断行」。
微操 2：图片位置锚定
选中图片 → 环绕文字选「嵌入型」（最不容易乱跑），或者选「四周型」后手动拖动，并在位置选项中勾选「对象随文字移动」。
